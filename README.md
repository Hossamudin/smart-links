# Smart Links — link.khabeer.online

Arabic-first content hub for Khabeer videos: one page per video with every asset (links, prompts, files, related videos), plus a gateway for the audience (requests, questions, notify-me, rewards). Integrates with Switchy (short links/QR) and Mailercloud (leads), and is managed via an admin panel and a secure API/MCP.

See [docs/PLAN.md](docs/PLAN.md) for the full plan.

> Never commit secrets. All keys live in Coolify environment variables.
